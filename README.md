# IDS-AI

Hybrid AI-powered Intrusion Detection System — combines a Machine Learning model and a local LLM (Mistral-7B) to classify network traffic in real time.

## Architecture

```text
IDS-AI/
├── backend/
│   ├── data.csv              # Network dataset (211,043 entries, 44 columns)
│   ├── train.py              # Training + automatic best-model selection
│   ├── detector.py           # ML inference pipeline
│   ├── model.py              # LLM integration (Mistral-7B via HuggingFace)
│   ├── main.py               # FastAPI app (POST /analyze, GET /health)
│   ├── best_model.joblib     # Saved model bundle (generated by train.py)
│   └── requirements.txt
├── frontend/                 # React UI
└── database/                 # MongoDB configuration
```

## Detection Pipeline

```text
Network request
      │
      ▼
 [Preprocessing]
 Categorical encoding + normalization
      │
      ▼
 [ML Model]  ─────── normal ───────────▶  { label: normal, confidence }
 RF / XGBoost / IsoForest
      │
   anomaly
      │
      ▼
 [LLM — Mistral-7B]
 Classification + explanation
      │
      ▼
 { Normal | Suspicious | Malicious, confidence, explanation, severity }
```

## Trained ML Models

| Model                  | Type                              |
| ---------------------- | --------------------------------- |
| RandomForestClassifier | Supervised                        |
| XGBClassifier          | Supervised                        |
| IsolationForest        | Unsupervised (anomaly detection)  |

The best model is **automatically** selected by F1-score and saved to `best_model.joblib`.

## Quick Start

### 1. Backend

```bash
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

### 2. Training

```bash
python train.py
```

Prints a comparison table for all 3 models and saves the best one:

```text
------------------------------------------------------------------------------
Model                   Accuracy  Precision   Recall       F1
------------------------------------------------------------------------------
RandomForest              0.9912     0.9934   0.9928   0.9931
XGBoost                   0.9905     0.9921   0.9919   0.9920
IsolationForest           0.7841     0.8102   0.7630   0.7859
------------------------------------------------------------------------------
```

### 3. Start the API

```bash
uvicorn main:app --reload
```

API available at `http://localhost:8000` · Interactive docs: `http://localhost:8000/docs`

## API Endpoints

### `POST /analyze`

Analyzes a network event through the full pipeline (ML + LLM if anomaly).

**Request body (all fields are optional):**

```json
{
  "src_ip": "192.168.1.10",
  "dst_ip": "10.0.0.1",
  "src_port": 4444,
  "dst_port": 80,
  "proto": "tcp",
  "service": "-",
  "conn_state": "SF",
  "duration": 12.5,
  "src_bytes": 10240,
  "dst_bytes": 512,
  "src_pkts": 20,
  "dst_pkts": 5
}
```

**Response:**

```json
{
  "timestamp": "2026-04-17T10:23:00Z",
  "ml_label": "attack",
  "ml_confidence": 0.97,
  "ml_model": "RandomForest",
  "is_anomaly": true,
  "classification": "Malicious",
  "llm_confidence": 0.91,
  "explanation": "Connection on port 4444 with a high volume of source bytes — characteristic of a backdoor.",
  "llm_available": true,
  "severity": "high",
  "src_ip": "192.168.1.10",
  "dst_ip": "10.0.0.1"
}
```

## Environment Variables

| Variable          | Default                               | Description                          |
| ----------------- | ------------------------------------- | ------------------------------------ |
| `IDS_MODEL_PATH`  | `backend/best_model.joblib`           | Path to the model bundle             |
| `LLM_MODEL_NAME`  | `mistralai/Mistral-7B-Instruct-v0.2`  | HuggingFace model to use             |
| `LLM_DEVICE`      | `auto`                                | `cpu`, `cuda`, or `auto`             |
| `LLM_ENABLED`     | `true`                                | Disable the LLM by setting `false`   |
| `LLM_PRELOAD`     | `false`                               | Load the LLM at startup              |
| `CORS_ORIGINS`    | `http://localhost:3000`               | Allowed CORS origins                 |
| `MONGODB_URI`     | `mongodb://localhost:27017`           | MongoDB URI                          |

> **Note**: Mistral-7B requires ~14 GB of RAM/VRAM. On machines without a GPU, set `LLM_DEVICE=cpu` or disable with `LLM_ENABLED=false`.
